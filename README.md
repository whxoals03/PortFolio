# Portfolio

소프트웨어 개발 과정에서 진행한 프로젝트를 정리한 포트폴리오입니다.

C#, Python, HTML, CSS, JavaScript 등을 활용하여 데스크톱 프로그램, 웹 프로젝트, 머신러닝 프로젝트를 구현했습니다.
각 프로젝트 폴더에서 소스 코드 및 프로젝트 파일을 확인할 수 있습니다.

---

## Projects

### 1. 개인자산 관리 프로그램

**C# / WinForms / SQLite**

개인의 수입, 지출 및 예산을 관리하기 위해 제작한 데스크톱 프로그램입니다.

* 로그인 및 회원 관리
* 수입·지출 내역 관리
* 예산 설정
* 자산 현황 확인
* SQLite를 이용한 데이터 저장
* PDF 저장 기능
