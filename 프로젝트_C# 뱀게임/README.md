# Snake Game

C# Windows Forms를 활용하여 제작한 뱀게임입니다.
키보드 입력과 Timer 이벤트를 이용해 뱀의 이동, 먹이 생성,
충돌 판정, 점수 계산 등의 기본 게임 기능을 구현했습니다.

## 프로젝트 개요

- 개발 목적: C# 이벤트 처리와 좌표 기반 게임 로직 학습
- 개발 형태: 개인 프로젝트
- 개발 환경: Visual Studio
- 개발 언어: C#
- Framework: Windows Forms

## 주요 기능

### 1. 뱀 이동
- 방향키를 이용하여 상하좌우 이동
- Timer를 이용하여 일정 시간마다 자동 이동
- 현재 진행 방향의 반대 방향으로 즉시 이동하지 못하도록 처리

### 2. 먹이 생성
- 게임 화면 내부에 먹이를 랜덤하게 생성
- 뱀이 먹이를 먹으면 새로운 위치에 먹이 생성

### 3. 뱀 길이 증가
- 먹이를 먹으면 몸통의 길이가 증가
- 뱀의 위치 데이터를 이용하여 몸통 이동 처리

### 4. 점수 시스템
- 먹이를 먹을 때마다 점수 증가
- 현재 점수를 화면에 표시

### 5. 충돌 처리
- 벽에 충돌하면 게임 종료
- 자신의 몸통과 충돌하면 게임 종료

## 조작 방법

| 키 | 기능 |
|---|---|
| ↑ | 위로 이동 |
| ↓ | 아래로 이동 |
| ← | 왼쪽 이동 |
| → | 오른쪽 이동 |

## 구현 과정

게임을 구현하면서 가장 중요하게 다룬 부분은
뱀의 머리와 몸통의 위치를 관리하는 것이었습니다.

Timer 이벤트가 발생할 때마다 뱀의 현재 위치를 갱신하고,
이전 몸통의 위치를 다음 몸통이 따라가도록 구현했습니다.

또한 먹이와 뱀 머리의 좌표를 비교하여 충돌 여부를 판단하고,
먹이를 먹었을 경우 몸통을 추가하도록 구현했습니다.

## 구현하면서 해결한 문제

### 방향 전환 문제
처음에는 오른쪽으로 이동 중인 상태에서
왼쪽 방향키를 누르면 뱀이 바로 자신의 몸과 충돌하는 문제가 있었습니다.

현재 이동 방향과 반대 방향의 입력을 제한하여
해당 문제를 해결했습니다.

### 먹이 위치 문제
랜덤으로 생성된 먹이가 뱀의 몸 위에 생성될 가능성이 있었습니다.

먹이 생성 시 뱀의 현재 위치와 비교한 후,
겹치는 경우 다시 위치를 생성하도록 처리했습니다.
