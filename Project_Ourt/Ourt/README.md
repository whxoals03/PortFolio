# Ourt - 의류 쇼핑몰 웹 프로젝트

HTML, CSS, JavaScript를 활용하여 제작한 남성 의류 쇼핑몰 웹 프로젝트입니다.
쇼핑몰의 메인 화면부터 상품 목록, 상품 상세 정보, 장바구니까지 기본적인 쇼핑몰 이용 흐름을 구현했습니다.

## 주요 기능

* 쇼핑몰 메인 화면 구성
* `ONLINE STORE` 메뉴 Hover 기능
* `ONLINE STORE` 하위 카테고리 중 **SHIRTS 페이지 구현**
* SHIRTS 상품 목록 출력
* 상품 선택 시 상세 페이지 이동
* 상품 상세 정보 및 이미지 표시
* 상품 장바구니 추가
* 장바구니 상품 및 수량 확인
* `localStorage`를 이용한 장바구니 데이터 저장
* 로고 및 메뉴를 이용한 페이지 간 이동

> 현재 `ONLINE STORE`의 전체 카테고리 중 **SHIRTS 카테고리만 구현되어 있습니다.**

## 사용 기술

* HTML
* CSS
* JavaScript
* LocalStorage

## 프로젝트 구성

* `Ourt.html` : 쇼핑몰 메인 페이지
* `SHIRTS.html` : 셔츠 상품 목록 페이지
* `PRODUCT.html` : 상품 상세 페이지
* `BAG.html` : 장바구니 페이지
* `PRODUCTS_DATA.js` : 상품 데이터 관리
* `pic/` : 상품 및 사이트 이미지
