HTML, CSS, JavaScript를 활용하여 제작한 남성 의류 쇼핑몰 웹 프로젝트입니다.

쇼핑몰의 메인 화면부터 상품 목록, 상품 상세 정보, 장바구니까지 기본적인 쇼핑몰 이용 흐름을 구현했습니다.
현재 `ONLINE STORE`의 전체 카테고리 중 **SHIRTS 카테고리**를 중심으로 구현되어 있습니다.

## 주요 기능

* 쇼핑몰 메인 화면 구성
* `ONLINE STORE` 메뉴 Hover 기능
* `ONLINE STORE` 하위 카테고리 중 **SHIRTS 페이지 구현**
* SHIRTS 상품 목록 출력
* 상품 선택 시 상세 페이지 이동
* 상품 상세 정보 및 이미지 표시
* 상품 장바구니 추가
* 장바구니 상품 및 수량 확인
* `localStorage`를 이용한 장바구니 데이터 저장
* 로고 및 메뉴를 이용한 페이지 간 이동

> 현재 `ONLINE STORE`의 전체 카테고리 중 **SHIRTS 카테고리만 구현되어 있습니다.**

## 사용 기술

* **HTML**

  * 쇼핑몰 페이지 구조 및 상품 정보 구성

* **CSS**

  * 메인 화면, 상품 목록, 상세 페이지, 장바구니 UI 구성
  * Hover 효과 및 레이아웃 구현

* **JavaScript**

  * 메뉴 동작 및 페이지 이동
  * 상품 데이터 출력
  * 상품 상세 정보 처리
  * 장바구니 기능 구현

* **LocalStorage**

  * 장바구니 데이터를 브라우저에 저장
  * 페이지 이동 후에도 장바구니 데이터를 유지

## 핵심 구현 내용

### 1. 상품 데이터 관리

상품 정보를 `PRODUCTS_DATA.js`에서 관리하도록 구성했습니다.

상품명, 가격, 할인율, 이미지 등의 정보를 JavaScript 데이터로 관리하고 상품 목록과 상세 페이지에서 필요한 상품 정보를 불러와 사용할 수 있도록 구현했습니다.

이를 통해 상품 정보를 HTML에 직접 반복해서 작성하는 방식을 줄이고 상품 데이터를 한 곳에서 관리할 수 있도록 구성했습니다.

---

### 2. 공통 상품 상세 페이지

초기에는 상품마다 각각의 HTML 상세 페이지를 사용하는 방식으로 구현했습니다.

하지만 상품이 증가할수록 상세 페이지 파일도 함께 증가하는 문제가 있어 `PRODUCT.html` 하나를 공통 상품 상세 페이지로 사용하는 구조로 변경했습니다.

상품을 선택하면 해당 상품의 정보를 확인하여 `PRODUCT.html`에서 상품 이미지와 정보를 출력하도록 구성했습니다.

---

### 3. 장바구니 기능

상품 상세 페이지에서 선택한 상품을 장바구니에 추가할 수 있도록 구현했습니다.

장바구니 데이터는 브라우저의 `localStorage`에 저장하여 다른 페이지로 이동하거나 새로고침한 이후에도 데이터를 유지할 수 있도록 했습니다.

`BAG.html`에서는 저장된 데이터를 불러와 장바구니에 추가된 상품과 수량을 확인할 수 있도록 구현했습니다.

---

### 4. 쇼핑몰 페이지 이동 흐름

사용자가 실제 쇼핑몰을 이용하는 흐름을 기준으로 페이지를 구성했습니다.

**메인 화면 → SHIRTS 상품 목록 → 상품 상세 페이지 → 장바구니**

로 이어지는 구조를 구현했으며, 로고와 메뉴를 이용하여 각 페이지 사이를 이동할 수 있도록 구성했습니다.

---

## 문제 해결 및 개선

### 상품 상세 페이지 구조 개선

처음에는 상품별로 `pic1.html`, `pic2.html`, `pic3.html`과 같이 각각의 상세 페이지를 생성하는 방식으로 구현했습니다.

이 방식은 상품이 추가될 때마다 새로운 HTML 파일을 만들어야 하기 때문에 상품 수가 증가할수록 파일 관리가 어려워지는 문제가 있었습니다.

이를 개선하기 위해 상품 데이터를 `PRODUCTS_DATA.js`에서 관리하고, `PRODUCT.html` 하나에서 선택한 상품의 정보를 출력하는 방식으로 구조를 변경했습니다.

이를 통해 상품이 추가되더라도 상세 페이지 HTML을 새로 만들 필요 없이 상품 데이터 추가를 중심으로 관리할 수 있도록 개선했습니다.

---

### 장바구니 데이터 유지

페이지를 이동하더라도 사용자가 추가한 장바구니 상품이 유지되어야 했습니다.

이를 위해 JavaScript의 `localStorage`를 이용하여 장바구니 데이터를 브라우저에 저장하고, 장바구니 페이지에서 저장된 데이터를 다시 불러오는 방식으로 구현했습니다.

이를 통해 페이지 간 이동 이후에도 장바구니 정보를 유지할 수 있도록 했습니다.

## 프로젝트 구성

```text
Ourt/
│
├── Ourt.html
├── SHIRTS.html
├── PRODUCT.html
├── BAG.html
│
├── Ourt.js
├── PRODUCTS_DATA.js
│
├── CSS/
├── JS/
│
└── pic/
```

주요 파일의 역할은 다음과 같습니다.

* `Ourt.html` : 쇼핑몰 메인 페이지
* `SHIRTS.html` : SHIRTS 상품 목록 페이지
* `PRODUCT.html` : 공통 상품 상세 페이지
* `BAG.html` : 장바구니 페이지
* `PRODUCTS_DATA.js` : 상품 데이터 관리
* `pic/` : 상품 및 사이트 이미지

## 구현 범위

본 프로젝트는 전체 의류 쇼핑몰 서비스를 완성하는 것을 목표로 하기보다 HTML, CSS, JavaScript를 활용하여 **상품 탐색부터 장바구니까지 이어지는 기본적인 쇼핑몰 이용 흐름을 구현하는 것**에 중점을 두었습니다.

현재 `ONLINE STORE` 메뉴 중 **SHIRTS 카테고리만 구현되어 있으며**, 로그인, 회원가입, 결제, 서버 및 데이터베이스 연동 기능은 구현 범위에 포함하지 않았습니다.
