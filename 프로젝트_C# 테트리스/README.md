# Tetris

C# Windows Forms를 활용하여 제작한 테트리스 게임입니다.
키보드 입력과 Timer 이벤트를 이용하여 블록 이동, 회전, 자동 하강, 충돌 판정, 줄 제거 등 테트리스의 기본적인 게임 기능을 구현했습니다.

## 프로젝트 개요

* 개발 목적: C#을 활용한 좌표 기반 게임 로직과 이벤트 처리 학습
* 개발 형태: 개인 프로젝트
* 개발 환경: Visual Studio
* 개발 언어: C#
* Framework: Windows Forms

## 주요 기능

### 1. 테트리스 블록 생성

* 게임 시작 시 새로운 블록 생성
* 여러 종류의 테트리스 블록 사용
* 블록을 게임판 상단에서 생성하여 아래 방향으로 이동

### 2. 블록 이동

* 키보드 입력을 통해 블록을 좌우로 이동
* 아래 방향키를 이용한 빠른 하강
* 게임판의 경계를 벗어나지 않도록 이동 가능 여부 확인

### 3. 블록 회전

* 키보드 입력을 통해 현재 블록 회전
* 회전 후 게임판 경계를 벗어나거나 다른 블록과 겹치는지 확인
* 정상적인 위치에서만 회전하도록 처리

### 4. 자동 하강

* Timer 이벤트를 이용하여 일정 시간마다 블록이 한 칸씩 아래로 이동
* 더 이상 내려갈 수 없는 경우 현재 블록을 게임판에 고정
* 블록이 고정되면 새로운 블록 생성

### 5. 충돌 판정

블록이 이동하거나 회전할 때 다음 조건을 확인합니다.

* 게임판의 왼쪽 경계를 벗어나는지 확인
* 게임판의 오른쪽 경계를 벗어나는지 확인
* 게임판의 아래쪽 경계를 벗어나는지 확인
* 이미 고정된 다른 블록과 겹치는지 확인

이동이 불가능한 경우 해당 동작을 실행하지 않도록 처리했습니다.

### 6. 완성된 줄 제거

* 한 줄의 모든 칸이 블록으로 채워졌는지 확인
* 완성된 줄을 게임판에서 제거
* 제거된 줄 위에 있던 블록을 한 칸씩 아래로 이동
* 여러 줄이 동시에 완성된 경우에도 줄 제거 처리

### 7. 게임 오버

새로운 블록을 생성할 위치에 이미 다른 블록이 존재하면 더 이상 게임을 진행할 수 없는 상태로 판단하여 게임을 종료합니다.

## 조작 방법

| 키 | 기능        |
| - | --------- |
| ← | 블록 왼쪽 이동  |
| → | 블록 오른쪽 이동 |
| ↓ | 블록 아래 이동  |
| ↑ | 블록 회전     |

## 구현 과정

테트리스를 구현하면서 게임 화면을 일정한 크기의 격자로 나누고, 각 칸에 블록이 존재하는지를 데이터로 관리하도록 구성했습니다.

현재 움직이고 있는 블록과 게임판에 이미 고정된 블록을 구분하여 관리하고, Timer 이벤트가 발생할 때마다 현재 블록이 아래로 이동할 수 있는지 검사하도록 구현했습니다.

블록이 더 이상 아래로 이동할 수 없는 경우 현재 블록의 위치를 게임판 데이터에 저장하여 고정하고, 완성된 줄이 있는지 검사한 뒤 새로운 블록을 생성하도록 게임의 진행 순서를 구성했습니다.

또한 키보드 이벤트를 이용하여 사용자가 블록을 좌우로 이동하거나 회전할 수 있도록 했으며, 모든 이동과 회전 전에는 해당 위치로 이동할 수 있는지 먼저 검사하도록 처리했습니다.

## 구현하면서 해결한 문제

### 블록이 게임판 밖으로 이동하는 문제

처음에는 키보드 입력에 따라 블록의 좌표만 변경하여 게임판의 좌우 경계를 벗어나는 문제가 발생할 수 있었습니다.

블록을 실제로 이동시키기 전에 변경될 좌표가 게임판 내부에 존재하는지 확인하고, 유효한 경우에만 이동하도록 처리했습니다.

### 다른 블록과 겹치는 문제

현재 블록이 아래로 내려가거나 좌우로 이동할 때 이미 고정된 블록의 위치와 겹치는 문제가 발생할 수 있었습니다.

게임판에 저장된 블록 데이터와 현재 블록의 이동 예정 좌표를 비교하여 겹치는 경우 이동을 제한하도록 구현했습니다.

### 블록 회전 시 충돌 문제

블록을 게임판 가장자리에서 회전할 경우 일부 블록이 게임판 외부로 나가거나 다른 블록과 겹칠 수 있었습니다.

회전된 상태의 좌표를 먼저 계산한 뒤 해당 위치가 유효한지 검사하고, 이동 가능한 경우에만 회전 결과를 적용하도록 처리했습니다.

### 줄 제거 후 블록 위치 문제

완성된 줄을 단순히 삭제하면 위쪽에 존재하는 블록이 그대로 남아 게임판에 빈 공간이 생기는 문제가 있었습니다.

줄을 제거한 이후 해당 줄보다 위에 있는 모든 블록 데이터를 한 칸씩 아래로 이동시키도록 처리하여 게임판이 정상적으로 이어지도록 구현했습니다.
