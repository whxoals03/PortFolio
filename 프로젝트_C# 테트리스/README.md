# Yut Game

C# Windows Forms를 활용하여 제작한 윷놀이 게임입니다.
윷을 던져 결과를 결정하고, 결과에 따라 말을 이동시키는 방식으로 윷놀이의 기본적인 게임 진행 구조를 구현했습니다.

## 프로젝트 개요

* 개발 목적: C#의 이벤트 처리와 조건문을 활용한 게임 로직 구현
* 개발 형태: 개인 프로젝트
* 개발 환경: Visual Studio
* 개발 언어: C#
* Framework: Windows Forms

## 주요 기능

### 1. 윷 던지기

* 버튼을 클릭하면 윷 던지기 실행
* 랜덤 값을 이용하여 도, 개, 걸, 윷, 모 결과 결정
* 결정된 결과를 화면에 표시

### 2. 말 이동

* 윷 결과에 따라 말의 이동 칸 수 결정
* 도: 1칸
* 개: 2칸
* 걸: 3칸
* 윷: 4칸
* 모: 5칸
* 현재 말의 위치를 기준으로 다음 위치 계산

### 3. 게임판 이동 처리

* 윷놀이 게임판의 각 위치를 기준으로 말 이동
* 이동한 말의 현재 위치를 화면에서 확인 가능
* 말의 위치 정보를 저장하여 다음 이동 시 활용

### 4. 윷 결과 출력

윷을 던진 결과에 따라 현재 결과를 사용자에게 표시합니다.

| 결과 | 이동 거리 |
| -- | ----: |
| 도  |    1칸 |
| 개  |    2칸 |
| 걸  |    3칸 |
| 윷  |    4칸 |
| 모  |    5칸 |

### 5. 게임 진행 상태 관리

* 현재 말의 위치 관리
* 윷을 던진 결과에 따라 게임 상태 변경
* 말이 이동할 때 이전 위치와 새로운 위치를 구분하여 처리

## 구현 과정

게임을 구현하면서 먼저 윷을 던지는 기능과 말이 이동하는 기능을 분리하여 제작했습니다.

윷 던지기 기능에서는 랜덤 값을 생성하고, 생성된 결과를 도, 개, 걸, 윷, 모 중 하나로 변환하도록 구현했습니다.

이후 각각의 결과에 해당하는 이동 거리를 설정하고, 현재 말의 위치에 이동 거리를 더하여 새로운 위치를 계산하도록 구성했습니다.

또한 말이 이동할 때 화면에 표시된 기존 말의 위치를 변경하여 사용자가 현재 게임 진행 상황을 확인할 수 있도록 구현했습니다.

## 구현하면서 해결한 문제

### 윷 결과와 이동 거리 연결

처음에는 윷을 던지는 결과와 실제 말의 이동 기능이 서로 분리되어 있어 결과는 정상적으로 출력되지만 말이 이동하지 않는 문제가 있었습니다.

각 윷 결과에 대응하는 이동 값을 설정하고, 해당 값을 말의 현재 위치에 적용하도록 수정하여 문제를 해결했습니다.

### 말의 현재 위치 관리

말을 이동시킬 때마다 화면상의 위치만 변경하면 다음 이동에서 이전 위치를 정확하게 확인하기 어려운 문제가 있었습니다.

말의 현재 위치를 별도의 변수로 관리하고, 이동이 발생할 때마다 해당 값을 갱신하도록 구현하여 연속적인 이동이 가능하도록 했습니다.

### 게임판 위치 처리

단순히 좌표 값을 일정하게 증가시키는 방식으로는 윷놀이판의 이동 경로를 정확하게 표현하기 어려웠습니다.

게임판의 이동 가능한 위치를 기준으로 말의 이동 경로를 구성하고, 현재 위치와 이동 거리를 이용하여 다음 위치를 결정하도록 처리했습니다.
