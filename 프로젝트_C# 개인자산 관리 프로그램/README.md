# Personal Asset Management

C# Windows Forms와 SQLite를 활용하여 제작한 개인 자산 관리 프로그램입니다.
사용자가 로그인한 뒤 수입과 지출을 기록하고, 현재 자산 현황과 예산을 확인할 수 있도록 구현했습니다.

단순한 수입·지출 입력 프로그램이 아니라 사용자 정보와 자산 데이터를 데이터베이스에 저장하고, 입력된 데이터를 기반으로 현재 자산 상태를 관리할 수 있도록 구성했습니다.

---

## 프로젝트 개요

* 개발 형태: 개인 프로젝트
* 개발 언어: C#
* 개발 환경: Visual Studio
* Framework: Windows Forms
* Database: SQLite
* 주요 기능: 로그인, 회원 관리, 수입·지출 관리, 예산 설정, 자산 현황 확인, 데이터 초기화, PDF 저장

---

## 개발 목적

C# Windows Forms를 활용하여 실제 사용 가능한 형태의 프로그램을 제작하고, UI와 데이터베이스를 연결하는 방법을 학습하기 위해 개발했습니다.

특히 사용자가 입력한 데이터를 프로그램 종료 후에도 유지하기 위해 SQLite 데이터베이스를 적용하고, 사용자별 수입과 지출 데이터를 관리할 수 있도록 구현했습니다.

또한 여러 화면을 연결하여 로그인부터 자산 관리까지 하나의 프로그램 흐름으로 구성하는 것을 목표로 했습니다.

---

## 주요 기능

### 1. 로그인

* 아이디와 비밀번호를 입력하여 로그인
* SQLite에 저장된 사용자 정보와 입력값 비교
* 로그인 성공 시 메인 화면으로 이동
* 로그인 실패 시 사용자에게 결과 안내

사용자 인증이 완료된 경우에만 자산 관리 기능을 사용할 수 있도록 구성했습니다.

---

### 2. 회원 관리

사용자의 계정 정보를 데이터베이스에 저장하여 관리합니다.

* 사용자 정보 등록
* 아이디 및 비밀번호 관리
* 로그인 시 등록된 사용자 정보 확인
* 사용자별 데이터 구분

SQLite의 `Users` 테이블을 이용하여 회원 정보를 관리하도록 구현했습니다.

---

## 데이터베이스 구성

프로그램에서 사용하는 주요 데이터는 SQLite 데이터베이스에 저장됩니다.

### Users

사용자의 로그인 정보를 저장합니다.

주요 데이터:

* 사용자 ID
* 아이디
* 비밀번호
* 사용자 정보

### Income

사용자의 수입 내역을 저장합니다.

주요 데이터:

* 사용자 정보
* 수입 금액
* 수입 항목
* 날짜
* 기타 입력 정보

### Expense

사용자의 지출 내역을 저장합니다.

주요 데이터:

* 사용자 정보
* 지출 금액
* 지출 항목
* 날짜
* 기타 입력 정보

사용자 정보와 자산 데이터를 분리하여 관리함으로써 프로그램의 데이터를 체계적으로 저장할 수 있도록 구성했습니다.

---

## 3. 홈 화면

로그인 후 사용자가 현재 자신의 자산 상태를 빠르게 확인할 수 있는 메인 화면입니다.

홈 화면에서는 등록된 수입과 지출 데이터를 기반으로 주요 정보를 확인할 수 있습니다.

* 현재 자산 현황
* 전체 수입
* 전체 지출
* 예산 정보
* 주요 자산 데이터 요약

여러 화면을 이동하지 않아도 현재 재정 상태를 확인할 수 있도록 구성했습니다.

---

## 4. 수입 관리

사용자가 발생한 수입을 직접 등록하고 관리할 수 있습니다.

### 주요 기능

* 수입 금액 입력
* 수입 항목 입력
* 수입 내역 저장
* 기존 수입 내역 조회
* 등록된 수입 데이터 화면 표시

입력된 수입 데이터는 SQLite의 `Income` 테이블에 저장되어 프로그램을 종료한 이후에도 유지됩니다.

---

## 5. 지출 관리

사용자가 발생한 지출 내역을 입력하고 관리할 수 있습니다.

### 주요 기능

* 지출 금액 입력
* 지출 항목 입력
* 지출 내역 저장
* 기존 지출 내역 조회
* 등록된 지출 데이터 화면 표시

입력된 지출 데이터는 SQLite의 `Expense` 테이블에 저장됩니다.

---

## 6. 수입·지출 내역 조회

등록된 수입과 지출 데이터를 DataGridView를 이용하여 화면에 표시했습니다.

사용자는 저장된 데이터를 목록 형태로 확인할 수 있으며, 여러 데이터를 한 화면에서 비교할 수 있도록 구성했습니다.

DataGridView와 SQLite 데이터를 연결하여 데이터베이스에 저장된 내용을 UI에서 확인할 수 있도록 구현했습니다.

---

## 7. 현재 자산 계산

등록된 수입과 지출 데이터를 이용하여 현재 자산을 계산합니다.

기본적인 계산 구조는 다음과 같습니다.

```text
현재 자산 = 전체 수입 - 전체 지출
```

새로운 수입 또는 지출이 추가되면 저장된 데이터를 다시 계산하여 현재 자산 상태에 반영하도록 구성했습니다.

---

## 8. 예산 설정

사용자가 사용할 수 있는 예산을 직접 설정할 수 있도록 구현했습니다.

예산을 설정하면 현재 지출과 비교하여 자산 관리에 활용할 수 있습니다.

이를 통해 단순히 지출 기록만 확인하는 것이 아니라 사용자가 자신의 소비 계획을 관리할 수 있도록 구성했습니다.

---

## 9. 데이터 초기화

필요한 경우 기존에 입력된 자산 데이터를 초기화할 수 있는 기능을 구현했습니다.

데이터 초기화 기능은 사용자의 기존 데이터를 변경하는 기능이기 때문에 실수로 실행되지 않도록 사용자 동작을 통해 실행되도록 구성했습니다.

---

## 10. PDF 저장

현재 프로그램에서 관리하고 있는 자산 정보를 PDF 형태로 저장할 수 있도록 구현했습니다.

이를 통해 프로그램 내부에서만 데이터를 확인하는 것이 아니라 별도의 문서 형태로 결과를 보관할 수 있도록 했습니다.

---

## 프로그램 동작 흐름

```text
프로그램 실행
        ↓
로그인 화면
        ↓
사용자 인증
        ↓
메인 화면
        ↓
수입 / 지출 / 예산 관리
        ↓
SQLite 데이터 저장
        ↓
자산 현황 계산 및 출력
        ↓
필요 시 PDF 저장
```

## 구현 과정

프로그램을 제작하면서 먼저 로그인 기능을 구현하여 사용자별로 프로그램을 사용할 수 있도록 구성했습니다.

이후 SQLite 데이터베이스를 연결하고 사용자 정보와 수입·지출 데이터를 각각 저장할 수 있도록 테이블을 구성했습니다.

수입과 지출 기능에서는 사용자가 입력한 정보를 데이터베이스에 저장하고, 저장된 데이터를 다시 조회하여 DataGridView에 출력하도록 구현했습니다.

홈 화면에서는 데이터베이스에 저장된 수입과 지출 데이터를 계산하여 사용자의 현재 자산 상태를 확인할 수 있도록 구성했습니다.

마지막으로 예산 설정, 데이터 초기화, PDF 저장과 같은 기능을 추가하여 단순한 CRUD 프로그램보다 실제 자산 관리 프로그램에 가까운 형태로 확장했습니다.

---

## 구현하면서 다룬 주요 내용

### 화면 간 데이터 연결

로그인 화면과 메인 화면이 서로 분리되어 있기 때문에 로그인한 사용자 정보를 다음 화면에서도 사용할 수 있도록 데이터를 전달해야 했습니다.

사용자 정보를 기준으로 데이터베이스를 조회하도록 구성하여 로그인한 사용자와 해당 사용자의 자산 데이터가 연결되도록 구현했습니다.

---

### 데이터베이스와 UI 연결

데이터베이스에 정상적으로 값이 저장되어도 사용자가 화면에서 확인할 수 없다면 프로그램을 사용할 수 없습니다.

SQLite에서 데이터를 조회한 뒤 DataGridView에 출력하여 저장된 수입과 지출 내역을 프로그램 화면에서 바로 확인할 수 있도록 구성했습니다.

---

### 수입·지출 데이터 반영

새로운 수입이나 지출을 입력한 뒤 메인 화면의 금액이 기존 값을 그대로 표시하면 실제 데이터와 화면의 정보가 달라지는 문제가 발생할 수 있습니다.

수입과 지출 데이터가 변경된 이후 다시 데이터를 불러와 합계를 계산하도록 구성하여 화면에 최신 정보가 반영되도록 했습니다.

---

### 여러 기능의 연결

로그인, 데이터 입력, 데이터베이스 저장, 목록 출력, 자산 계산 등의 기능을 각각 구현한 뒤 하나의 프로그램 흐름으로 연결해야 했습니다.

각 기능을 화면별로 분리하고 필요한 데이터를 데이터베이스를 기준으로 연결하여 프로그램 전체 구조를 구성했습니다.
